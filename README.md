# Corso di fotografia

Un corso di fotografia in italiano, dalle basi tecniche alla pratica avanzata.
Sito statico pubblicato con GitHub Pages.

- `index.html`: home con il simulatore di esposizione e il programma
- `corso/`: i moduli del corso
- `assets/`: stile e script
- `img/web` e `img/thumb`: foto in WebP (1600 px e 600 px)
- `data/exif.json`: dati di scatto delle foto
